PharmaSpark

基于3D Gaussian Splatting技术的分子可视化平台，专为药物发现和生物医学研究设计

GitHub 查看演示

核心功能

分子解析

支持PDB、SDF、MOL2、XYZ、PQR等多种分子文件格式的解析和处理

3D高斯溅射

将分子结构转换为高质量的3D高斯溅射数据，实现实时渲染

可视化选项

14种可视化模式、10种颜色方案，满足不同研究需求

用户系统

完整的用户注册、登录、个人中心和API配额管理

数据管理

分子上传、下载、保存、历史记录和标签管理

分析功能

分子分析、对接可视化、相似性搜索等功能
